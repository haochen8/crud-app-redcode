# Create the responsive book list

**Labels:** `frontend`, `ui`, `feature`, `priority: high`  
**Milestone:** M4 – Angular CRUD  
**Depends on:** #10, #13

## Purpose
Display all books on the authenticated home page with clear CRUD actions.

## Tasks
- [ ] Make `/books` the authenticated home route.
- [ ] Display title, author, and formatted publication date.
- [ ] Add “Add new book”, edit, and delete controls with accessible icons.
- [ ] Use a responsive table or mobile-friendly cards.
- [ ] Add loading, empty, and error states.

## Acceptance criteria
- Every API book is shown and actions work.
- All UI states are understandable.
- Mobile layout causes no page-level horizontal scrolling.
