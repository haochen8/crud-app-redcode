# Complete responsive, accessible UX

**Labels:** `frontend`, `accessibility`, `quality`, `priority: high`  
**Milestone:** M5 – My Quotes and UX  
**Depends on:** #14, #16, #19, #20

## Purpose
Make the application consistent and usable on phones, tablets, and desktops.

## Tasks
- [ ] Test at 360, 768, 1024, and 1440 px plus 200% zoom.
- [ ] Verify mobile navigation with mouse, touch, and keyboard.
- [ ] Remove horizontal scrolling and adapt forms/actions for small screens.
- [ ] Verify landmarks, labels, heading hierarchy, names, focus, and contrast.
- [ ] Standardize loading, empty, error, and success feedback.

## Acceptance criteria
- Every required flow works at all target widths.
- Controls never overlap and focus order is visible and logical.
- Both themes remain readable and accessible.
