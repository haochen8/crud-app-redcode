# Create the Angular 20 client

**Labels:** `frontend`, `setup`, `priority: high`  
**Milestone:** M1 – Foundation  
**Depends on:** #1

## Purpose
Create a strict, runnable Angular 20 application with the required UI dependencies.

## Tasks
- [ ] Scaffold `client/` with Angular CLI 20, routing, SCSS, and standalone components.
- [ ] Install Bootstrap 5.3, its JavaScript bundle, and Font Awesome through npm.
- [ ] Configure global styles and an environment-based API URL.
- [ ] Keep strict TypeScript and Angular compiler settings.
- [ ] Verify the development server, production build, and starter tests.

## Acceptance criteria
- Angular packages use major version 20.
- The build succeeds and Bootstrap plus Font Awesome render correctly.
- Services do not hard-code the API URL.
