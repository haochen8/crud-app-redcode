# Create Angular registration and login flows

**Labels:** `frontend`, `auth`, `priority: high`  
**Milestone:** M4 – Angular CRUD  
**Depends on:** #8, #10

## Purpose
Provide accessible registration and login forms.

## Tasks
- [ ] Add typed request/response models and `AuthService` methods.
- [ ] Build login and registration with Reactive Forms.
- [ ] Validate required fields, lengths, password, and confirmation.
- [ ] Show safe backend errors and request progress.
- [ ] Navigate after success and link both auth pages.

## Acceptance criteria
- Users can register and log in from the browser.
- Invalid forms are not submitted and failures are retryable.
- Fields have labels and full keyboard support.
